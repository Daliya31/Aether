FAQ

Frequently Asked Questions

Explore platform mechanics, billing policies, and security layers.

What is Aether Cloud edge hosting?
Aether Cloud compiles and executes serverless scripts directly at the CDN network nodes closest to the user. This cuts down round-trip delays, ensuring pages load in sub-10ms response times globally.
Can I link my own custom domains?
Yes. You can link custom domains with standard DNS CNAME mappings. Aether automatically handles SSL certification updates and renewals.
What build tools do you support?
We support all modern frontend engines (Next.js, SvelteKit, Vite, Nuxt, Astro). Aether CLI automatically parses package files and deploys builds.
Is there a cold start limit?
No. We operate pre-warmed container sandboxes at every edge cluster, meaning serverless processes resume in less than 50ms, bypassing AWS/Google Cloud latency.
How do you handle DDoS protection?
Every node has built-in layered DDoS scrubbers that identify and reject spam requests before they reach your hosting pipelines.
Where are environment variables stored?
Environment secrets are encrypted at rest using AES-256 standards and distributed to execution micro-environments dynamically.
