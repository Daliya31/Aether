# Aether Cloud — Landing Page

A premium, modern, and fully responsive one-page landing page designed for a high-performance tech startup.

## Features

- **Sticky Glassmorphism Navbar**: Elegant header with CSS backdrop-filtering that stays at the top on scroll, transitioning to a clean layout.
- **Hero Showcase**: High-impact typography, dark gradient mesh background, custom CTA buttons, and a clean CSS terminal mockup detailing CLI deployment steps.
- **Why Choose Us Section**: Responsive CSS Grid containing interactive 3D feature cards with Font Awesome icons.
- **Showcase & Statistics**: Side-by-side dashboard performance highlights and custom styled statistic cards.
- **Contact Form**: Sleek contact layout with input validation and clean UI fields.
- **Mobile Menu**: Responsive hamburger toggle menu optimized for mobile screens.

## Project Structure

```text
Maincraft/
├── index.html   # Main HTML5 layout and script
├── style.css    # Premium CSS3 styling & responsive layouts

```

## Technologies Used

- **HTML5**: Structured semantic markup.
- **CSS3**: Variables, Flexbox, CSS Grid, Transitions, Keyframe animations.
- **Google Fonts**: *Plus Jakarta Sans* (Headings) & *Inter* (Body).
- **Font Awesome**: CDN vector icons.

## Running Locally

To host this site locally, run one of the following commands in the project directory:

### Option 1: Node.js (http-server)
```bash
npx http-server -p 8080
```

### Option 2: Python
```bash
python -m http.server 8080
```

Once running, visit **http://localhost:8080/** in your web browser.
